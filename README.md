# Russian SSL Certificate Checker

Скрипт для мониторинга SSL-сертификатов. Умеет работать с сертификатами, выданными **НУЦ Минцифры** — их не видят обычные чекеры, потому что корневого сертификата нет в стандартном trust store.

## Зачем это нужно

После "определенных событий" многие российские сайты (госуслуги, банки, крупные компании) перешли на сертификаты Минцифры. Стандартные чекеры вроде `openssl s_client` и большинство Python-скриптов их не проверяют: цепочка не сходится к известному корню. Решил как пробный проект написать скрипт чекер.

## Что умеет

- Проверяет один домен или список из файла.
- Показывает, российский сертификат или нет (по `issuer`).
- Считает дни до истечения.
- Шлёт уведомление в Telegram, если осталось мало.
- Работает и с обычными сертификатами (Let's Encrypt и т.д.).

### Установка

```bash
git clone https://github.com/PavKole/rus-ce-check
cd rus-ce-check
pip install -r requirements.txt

#Скачай корневые сертификаты Минцифры в папку certs/:
cd certs
wget https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt
wget https://gu-st.ru/content/lending/russian_trusted_sub_ca_pem.crt
```

## Настройка Telegram (по желанию)
### Создай .env в корне проекта:
`TG_TOKEN=123456:ABC...`

`TG_CHAT_ID=987654321`
#### Если не хочешь уведомления — просто не создавай .env.

# Запуск

Проверить один домен:
`python ch_ssl.py --domain gosuslugi.ru --days 30`

Проверить список:
`python ch_ssl.py --file domains.txt --days 30`
--days — за сколько дней предупреждать. По умолчанию 30.

# Ограничения
Сайты с GOST TLS не проверяются: стандартный Python ssl их не понимает, нужна отдельная библиотека (например, pycads или gostcrypto). Пока не делал — не было задачи.
Проверяется только notAfter, цепочку полностью не парсю. Для большинства задач хватает.
