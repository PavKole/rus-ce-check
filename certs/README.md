# Корневые сертификаты

Сюда нужно положить корневые сертификаты российских УЦ.

## Откуда скачать

- Корневой: https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt
- Промежуточный: https://gu-st.ru/content/lending/russian_trusted_sub_ca_pem.crt

## Как положить

Скачай файлы и закоммить в эту папку под именами:
- `russian_trusted_root_ca_pem.crt`
- `russian_trusted_sub_ca_pem.crt`

Скрипт сам подхватит корневой сертификат при запуске.

## Важно

Эти сертификаты **не секретные**, их можно свободно распространять.
В стандартных хранилищах Linux/браузеров их по умолчанию нет,
поэтому они лежат в репозитории.
